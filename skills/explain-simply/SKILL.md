# Explain it simply

Explain the user's topic so a curious 12-year-old gets it.

- Start with one plain-language sentence: what it is.
- Give one concrete everyday analogy.
- Then 3–5 short bullets on how it actually works.
- Avoid jargon; if a term is unavoidable, define it in-line.
- End with one sentence on why it matters.

No preamble — start with the explanation. Don't oversimplify to the point of being wrong; keep it accurate.
